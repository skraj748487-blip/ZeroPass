# 🛡️ ZeroPass: पासवर्ड-मुक्त बायोमेट्रिक ऑथेंटिकेशन SDK

यह एक अगली पीढ़ी का ऑथेंटिकेशन फ्रेमवर्क है, जो पुराने पासवर्ड और SMS OTP की जगह एसिमेट्रिक क्रिप्टोग्राफी (RSA-2048) और बायोमेट्रिक सत्यापन का उपयोग करता है।

---

## 🌟 मुख्य विशेषताएं (Key Features)

- **ज़ीरो पासवर्ड / ज़ीरो OTP:** यूज़र को कोई पासवर्ड या कोड याद रखने की ज़रूरत नहीं।
- **RSA-2048 क्रिप्टोग्राफी:** प्राइवेट की डिवाइस में सुरक्षित रहती है, सर्वर पर सिर्फ पब्लिक की होती है।
- **बायोमेट्रिक सुरक्षा:** फोन के स्क्रीन लॉक या फिंगरप्रिंट सत्यापन के बिना मुहर नहीं लग सकती।
- **क्रॉस-डिवाइस ऑटो-लॉगिन:** कंप्यूटर स्क्रीन पर QR कोड स्कैन होते ही बिना रीलोड किए तुरंत लॉगिन।
- **प्लग-एंड-प्ले JS SDK:** किसी भी वेब ऐप में सिर्फ 2 लाइन कोड से इंटीग्रेशन।

---

## 🏗️ यह कैसे काम करता है? (How It Works)

1. **चैलेंज (Challenge):** सर्वर एक सुरक्षित सेशन टोकन बनाकर QR कोड दिखाता है।
2. **बायोमेट्रिक सत्यापन:** यूज़र मोबाइल से स्कैन करके स्क्रीन लॉक या फिंगरप्रिंट की पुष्टि करता है।
3. **डिजिटल मुहर:** फोन की प्राइवेट की टोकन पर डिजिटल हस्ताक्षर करती है।
4. **ऑटो-अनलॉक:** SQLite डेटाबेस में पब्लिक की से मुहर सत्यापित होते ही मुख्य स्क्रीन अनलॉक हो जाती है।

---

## 💻 डेवलपर इंटीग्रेशन (Integration Guide)

```html
<!-- 1. SDK लोड करें -->
<script src="http://localhost:5000/sdk.js"></script>

<!-- 2. लॉगिन कंटेनर जोड़ें -->
<div id="auth-container"></div>

<script>
  PasskeyVault.init({
    container: '#auth-container',
    onSuccess: (userId) => {
      console.log("सफल लॉगिन! यूज़र आईडी:", userId);
    }
  });
</script>
